# QGMF

The tiny, easy to use, feature complete Qt Graphics Modeling Framework

QGMF is a framework for graph creation and visualization
(C) Saïd LANKRI, under the GNU GPL License version 3

## QGMF library
C++ only tiny and easy to use Graph library for creating graphs based
on a model.

## QGMF graphics
Graphics widgets based on Qt Graphics Framework for visualizing and editing
QGMF graphs

# Build the source

## Compile

You need the Qt5 development files of the following modules:
- Qt Core
- Qt GUI

```
$ qmake
$ make
```

## Install

```
$ sudo make install
```
